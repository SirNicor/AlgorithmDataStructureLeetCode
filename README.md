# Algorithms and Data Structures

A personal collection of algorithm implementations, fundamental data structures, and competitive programming solutions in C#. 

I use this repository to practice problem-solving patterns, analyze time and space complexity, and keep core computer science concepts sharp.

## Repository Structure

- **`BinarySearch`**: Variations of binary search, plus classic sorting algorithms (Merge Sort, Quick Sort) and mathematical implementations (Euclidean algorithm, Factorial).
- **`DataStructure`**: From-scratch implementations of core data structures (e.g., Hash Tables) to understand their internal mechanics, memory allocation, and edge cases without relying on built-in libraries.
- **`LeetCode`**: Solutions to algorithmic problems, grouped by pattern or topic. 

## Tech Stack

- C# / .NET
- xUnit (for verifying edge cases and algorithmic correctness)

## Implementation Standards

When adding solutions to this repository, I focus on:
- **Complexity**: Prioritizing optimal time and space complexity (e.g., O(n) or O(n log n)) over brute-force O(n²) approaches.
- **Edge Cases**: Explicit handling of null inputs, empty collections, and integer overflow scenarios.
- **Readability**: Clean naming conventions and inline comments explaining non-obvious logic (e.g., sliding window or two-pointer mechanics).

## Running the Code

1. Open the solution in Visual Studio or JetBrains Rider.
2. Navigate to the specific folder or project of interest.
3. Run the console applications directly, or execute the associated unit tests to verify algorithm behavior.
